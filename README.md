# Oke Rodiat Portfolio

Welcome to the personal portfolio of Oke Rodiat, a UI/UX Designer and Web Developer. This portfolio showcases my skills, projects, and experiences in the field of web design and development.

View the portfolio at: [OKE RODIAT Portfolio](https://okerodiat6-sys.github.io/My-Portfolio/)
## Project Structure

The project is organized as follows:

```
oke-rodiat-portfolio
├── index.html          # Main HTML document for the portfolio website
├── css
│   └── styles.css     # CSS styles for the portfolio website
├── js
│   └── script.js      # JavaScript file for interactivity (if needed)
├── assets
│   ├── images
│   │   └── hero.jpg   # Placeholder image for the hero section
│   └── icons
│       └── favicon.svg # Favicon for the website
├── README.md          # Documentation for the project
└── .gitignore         # Files and directories to be ignored by version control
```

## Features

- **Responsive Design**: The portfolio is designed to be fully responsive, ensuring a seamless experience across devices.
- **Semantic HTML**: The use of semantic HTML elements improves accessibility and SEO.
- **Modern Aesthetics**: A clean and minimalist design that highlights my work and skills.
- **Interactive Elements**: JavaScript can be added for enhanced interactivity.

## Getting Started

To set up the portfolio locally, follow these steps:

1. Clone the repository:
   ```
   git clone <repository-url>
   ```

2. Navigate to the project directory:
   ```
   cd oke-rodiat-portfolio
   ```

3. Open `index.html` in your web browser to view the portfolio.

## Customization

Feel free to customize the following:

- **Images**: Replace the placeholder images in the `assets/images/` directory with your own.
- **Styles**: Modify the `css/styles.css` file to change the design and layout according to your preferences.
- **Content**: Update the `index.html` file to reflect your personal information, projects, and skills.
